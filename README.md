# ALA official website hero demo

Responsive static prototype of the `官网需求迭代_首屏改版` Pixso design.

## Included states

- Desktop hero at the 1920 × 1080 reference size
- Mobile hero at the 375 × 812 reference size
- Important security notice modal
- Help-center contact panel

## Run locally

```bash
python3 -m http.server 4185
```

Then open `http://127.0.0.1:4185`.

No build step or third-party runtime dependency is required.
